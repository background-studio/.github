# Background Studio

桌面应用背景增强套件。通过本机 CDP 注入自定义背景，不修改官方安装包。

## 仓库

| 仓库 | 说明 |
|------|------|
| [background-studio](https://github.com/background-studio/background-studio) | 统一壳：单托盘、安装/启停插件 |
| [codex_desktop_background](https://github.com/background-studio/codex_desktop_background) | Codex Background Studio（独立或作插件） |
| [notion_desktop_background](https://github.com/background-studio/notion_desktop_background) | Notion Background Studio（独立或作插件） |

## 推荐用法

1. 安装 [Background Studio](https://github.com/background-studio/background-studio/releases) 壳
2. 在壳里从各自 Release 安装 Codex / Notion 插件
3. Windows 托盘只保留一个 Background Studio

请勿同时运行「独立安装版」和「壳插件版」，否则可能出现双托盘。  
迁移说明：[docs/migration.md](https://github.com/background-studio/background-studio/blob/main/docs/migration.md)

非 OpenAI / Notion 官方产品。
